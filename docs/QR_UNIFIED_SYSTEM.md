# Unified QR Code System Documentation

## 🎯 Overview

The Unified QR Code System ensures **ALL** generated QR codes (Order & Reward) are always scannable and valid for POS and Kiosk payments. Every QR code generated by the system will:

✅ **Be scannable** by both POS and Kiosk scanners  
✅ **Automatically redirect** to payment upon successful scan  
✅ **Never show "Invalid QR"** for system-generated codes  
✅ **Include security tokens** to prevent tampering  
✅ **Have proper expiry times** (3hrs for orders, 30min for rewards)

## 📋 System Components

### 1. Core Library (`includes/qr_unified.php`)

Central QR code generation and validation system that provides:

- `generate_secure_qr_code($mysqli, $type, $id)` - Generate scannable QR with security token
- `validate_unified_qr($mysqli, $qr_data)` - Universal validation for all QR types
- `generate_qr_token($code, $type, $id)` - Create security token
- `validate_qr_token($code, $type, $id, $token)` - Verify security token

### 2. Universal API (`api/qr_universal_validate.php`)

Single endpoint for validating ALL QR codes from POS and Kiosk:

**Endpoint:** `POST /api/qr_universal_validate.php`

**Request:**
```json
{
  "code": "QR_CODE_DATA"
}
```

**Response (Success):**
```json
{
  "success": true,
  "type": "order",
  "code": "ORD12345678",
  "id": 123,
  "redirect_url": "payment.php?code=ORD12345678",
  "message": "Valid order QR code",
  "amount": 150.00
}
```

**Response (Error):**
```json
{
  "success": false,
  "error": "QR expired",
  "message": "Order QR code has expired (valid for 3 hours)"
}
```

### 3. Testing Tool (`admin/tools/qr_tester.php`)

Admin tool to test QR generation and validation:
- Generate QR codes for any order/reward
- Validate QR code data
- View QR payloads and tokens
- Test scannability

## 🔐 QR Code Format

### Order QR Codes

**Format:** `ORD + 8 alphanumeric characters`

**Example:** `ORDABC12345`

**JSON Payload:**
```json
{
  "type": "order",
  "code": "ORDABC12345",
  "token": "a1b2c3d4e5f6",
  "id": 123,
  "timestamp": 1704067200
}
```

**Properties:**
- Validity: **3 hours** from creation
- Can be scanned multiple times until paid
- Includes security token for validation

### Reward QR Codes

**Format:** `PHC- + 8 alphanumeric characters`

**Example:** `PHC-XYZ78901`

**JSON Payload:**
```json
{
  "type": "reward",
  "code": "PHC-XYZ78901",
  "token": "z9y8x7w6v5u4",
  "id": 456,
  "timestamp": 1704067200
}
```

**Properties:**
- Validity: **30 minutes** from creation
- Single-use only
- Includes security token for validation

## 💻 Implementation Guide

### Generate QR Code for New Order

```php
<?php
require_once __DIR__ . '/includes/qr_unified.php';
require_once __DIR__ . '/includes/qr_expiry_helper.php';

// After creating order
$order_id = $mysqli->insert_id;

// Generate QR code
$qr_data = generate_secure_qr_code($mysqli, 'order', $order_id);

if ($qr_data['success']) {
    // Set 3-hour expiry
    set_order_qr_expiry($mysqli, $order_id);
    
    // Display QR code
    echo '<img src="' . $qr_data['qr_image'] . '" alt="Order QR">';
    echo '<p>Code: ' . $qr_data['code'] . '</p>';
}
?>
```

### Generate QR Code for Reward

```php
<?php
require_once __DIR__ . '/includes/qr_unified.php';
require_once __DIR__ . '/includes/qr_expiry_helper.php';

// After creating voucher
$voucher_id = $mysqli->insert_id;

// Generate QR code
$qr_data = generate_secure_qr_code($mysqli, 'reward', $voucher_id);

if ($qr_data['success']) {
    // Set 30-minute expiry
    set_voucher_expiry($mysqli, $voucher_id);
    
    // Display QR code
    echo '<img src="' . $qr_data['qr_image'] . '" alt="Reward QR">';
    echo '<p>Code: ' . $qr_data['code'] . '</p>';
}
?>
```

### Validate QR Code (Backend)

```php
<?php
require_once __DIR__ . '/includes/qr_unified.php';

$qr_code = $_POST['qr_code'];

$result = validate_unified_qr($mysqli, $qr_code);

if ($result['success']) {
    // Redirect to payment
    header('Location: ' . $result['redirect_url']);
} else {
    // Show error
    echo $result['message'];
}
?>
```

### Scanner Integration (JavaScript)

```javascript
// Using html5-qrcode library
const scanner = new Html5QrcodeScanner('reader', { fps: 10, qrbox: 200 });

scanner.render(async (decodedText) => {
    // Validate via universal API
    const response = await fetch('/api/qr_universal_validate.php', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ code: decodedText })
    });
    
    const data = await response.json();
    
    if (data.success) {
        // Auto-redirect to payment
        window.location.href = data.redirect_url;
    } else {
        alert(data.message);
    }
});
```

## 🛡️ Security Features

### Token-Based Validation

Every QR code includes a secure HMAC token:
- Generated using secret key + date
- Prevents tampering and forgery
- Valid for current day + previous day (timezone grace)

### Expiry Enforcement

- **Orders:** 3-hour validity (configurable)
- **Rewards:** 30-minute validity (configurable)
- Enforced server-side, not just UI
- Cannot be bypassed by manipulating QR code

### Status Checks

Before accepting QR code:
- ✓ Checks if order already paid
- ✓ Checks if order cancelled
- ✓ Checks if reward already redeemed
- ✓ Validates expiry time
- ✓ Verifies security token

## ❌ Common Issues & Solutions

### Issue: "Invalid QR Code" on Scan

**Solution:**
1. Check QR format matches `ORD######` or `PHC-######`
2. Verify order/voucher exists in database
3. Check expiry time hasn't passed
4. Test with QR Tester tool

### Issue: QR Code Not Scanning

**Solution:**
1. Increase QR size (min 200x200px)
2. Use high error correction level (H)
3. Ensure good contrast (black on white)
4. Check camera permissions

### Issue: "Already Paid/Redeemed"

**Solution:**
- This is expected behavior for used QR codes
- Generate new QR code if needed
- Check order/voucher status in database

## 📈 Best Practices

1. **Always use `generate_secure_qr_code()`** - Never manually create QR codes
2. **Set expiry times immediately** - Call `set_order_qr_expiry()` or `set_voucher_expiry()`
3. **Use universal API** - Both POS and Kiosk should use `/api/qr_universal_validate.php`
4. **Display countdown timers** - Show users how much time remains
5. **High quality images** - Use at least 200x200px with error correction level H
6. **Test regularly** - Use QR Tester tool to verify scannability
